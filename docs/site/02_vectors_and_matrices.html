02. Vecteurs, Matrices et Métriques VMLS

Les classes Vector et Matrix incarnent les structures de données fondamentales de linalg_pedagopy.

Conformément à la philosophie du package : - Immutabilité absolue : Toute opération renvoie une nouvelle instance. Aucune modification en place n'est autorisée. - Exactitude symbolique : Les coefficients sont convertis en expressions SymPy exactes (sp.Expr). - Protection anti-triche : Les constructeurs rejettent les proxys verrouillés du tuteur pour empêcher les contournements.

1. La classe Vector

Un Vector représente un vecteur colonne de ACADEMIC_TOKEN_4 (de dimension formelle ACADEMIC_TOKEN_5).

1.1 Initialisation et constructeurs d'usine

Python
from linalg_pedagopy import Vector
import sympy as sp
from fractions import Fraction

# Initialisation par une séquence de scalaires exacts
v = Vector([1, "2/3", Fraction(4, 5), sp.sqrt(3)])
print(v)          # (1, 2/3, 4/5, sqrt(3))
print(v.size)     # 4
print(v.shape)    # (4, 1)

# Constructeurs d'usine remarquables
z = Vector.zeros(3)          # Vecteur nul (0, 0, 0)
u = Vector.ones(4)           # Vecteur unitaire tout à 1 (1, 1, 1, 1)
e2 = Vector.unit(1, 4)       # 2e vecteur de la base canonique e₂ = (0, 1, 0, 0) (indice 0-based)

1.2 Opérations algébriques

Python
v1 = Vector([1, 2, 3])
v2 = Vector([4, 5, 6])

# Addition et soustraction
w1 = v1 + v2       # (5, 7, 9)
w2 = v1 - v2       # (-3, -3, -3)

# Multiplication scalaire (gauche et droite)
w3 = 3 * v1        # (3, 6, 9)
w4 = v1 * "1/2"    # (1/2, 1, 3/2)

# Négation
w5 = -v1           # (-1, -2, -3)

1.3 Métriques et géométrie VMLS

linalg_pedagopy implémente l'ensemble des métriques géométriques introduites dans les chapitres 1 à 3 de VMLS :

Méthode Définition Mathématique Description VMLS
v.dot(w) ou v @ w ACADEMIC_TOKEN_6 Produit scalaire standard.
v.norm_sq() ACADEMIC_TOKEN_7 Carré de la norme euclidienne (rationnel si ACADEMIC_TOKEN_8).
v.norm() ACADEMIC_TOKEN_9 Norme euclidienne exacte.
v.unit_vector() ACADEMIC_TOKEN_10 Vecteur normalisé (direction).
v.dist(w) ACADEMIC_TOKEN_11 Distance euclidienne entre ACADEMIC_TOKEN_12 et ACADEMIC_TOKEN_13.
v.rms() ACADEMIC_TOKEN_14 Valeur efficace (Root-Mean-Square).
v.mean() ACADEMIC_TOKEN_15 Moyenne arithmétique des coefficients.
v.std() ACADEMIC_TOKEN_16 Écart-type (écart quadratique moyen à la moyenne).
v.angle(w) ACADEMIC_TOKEN_17 Angle non orienté en radians.
v.correlation(w) ACADEMIC_TOKEN_18 Coefficient de corrélation de Pearson.
v.project_onto(w) ACADEMIC_TOKEN_19 Projection orthogonale de ACADEMIC_TOKEN_20 sur la droite ACADEMIC_TOKEN_21.
v.orthogonal_complement(w) ACADEMIC_TOKEN_22 Composante orthogonale de ACADEMIC_TOKEN_23 par rapport à ACADEMIC_TOKEN_24.

Exemple :

Python
a = Vector([1, 2, 2])
b = Vector([2, 0, 1])

print(a.norm())                   # 3
print(a.dot(b))                   # 4
print(a.angle(b))                 # acos(4*sqrt(5)/15)
print(a.project_onto(b))          # (8/5, 0, 4/5)
print(a.orthogonal_complement(b)) # (-3/5, 2, 6/5)

1.4 Vecteurs par blocs et conversions

Python
# Concaténation par blocs
v_block = Vector.block([Vector([1, 2]), Vector([3, 4, 5])])
print(v_block)  # (1, 2, 3, 4, 5)

# Conversion en Matrix ou SymPy Matrix
M = a.to_matrix()    # Matrix 3x1
sp_col = a.to_sympy() # sympy.Matrix 3x1

2. La classe Matrix

Une Matrix représente une matrice ACADEMIC_TOKEN_25 sur ACADEMIC_TOKEN_26.

2.1 Initialisation et constructeurs d'usine

Python
from linalg_pedagopy import Matrix

# Initialisation par une liste de lignes
A = Matrix([
    [1, 2, 3],
    [4, 5, 6]
])
print(A.shape)   # (2, 3)
print(A.nrows)   # 2 (nombre de lignes)
print(A.ncols)   # 3 (nombre de colonnes)

# Constructeurs d'usine
I3 = Matrix.identity(3)        # Matrice identité 3x3
Z = Matrix.zeros(2, 4)         # Matrice nulle 2x4
D = Matrix.diagonal([2, -1, 5]) # Matrice diagonale diag(2, -1, 5)

# Construction à partir de colonnes ou de lignes
col1 = Vector([1, 0])
col2 = Vector([2, 3])
M = Matrix.from_columns([col1, col2])

2.2 Opérations matricielles usuelles

Python
A = Matrix([[1, 2], [3, 4]])
B = Matrix([[2, 0], [1, 2]])

# Somme, différence et produit scalaire
C = A + B
D = A - B
E = 2 * A

# Produit matriciel (opérateur @)
P = A @ B          # Matrix([[4, 4], [10, 8]])

# Transposée
AT = A.T           # Matrix([[1, 3], [2, 4]])

# Puissance entière (matrices carrées)
A_cubed = A ** 3

3. Les 4 vues du produit matriciel (VMLS §10.1)

L'ouvrage VMLS insiste sur quatre interprétations équivalentes mais conceptuellement distinctes du produit matriciel ACADEMIC_TOKEN_27. linalg_pedagopy propose des méthodes explicites pour illustrer chacune d'elles :

ACADEMIC_TOKEN_0

3.1 Vue 1 : Combinaisons linéaires des colonnes de ACADEMIC_TOKEN_28

Chaque colonne ACADEMIC_TOKEN_29 de ACADEMIC_TOKEN_30 est une combinaison linéaire des colonnes ACADEMIC_TOKEN_31 de ACADEMIC_TOKEN_32, avec pour coefficients les composantes de la ACADEMIC_TOKEN_33-ième colonne de ACADEMIC_TOKEN_34 : ACADEMIC_TOKEN_1

3.2 Vue 2 : Produits scalaires ligne-colonne

Chaque coefficient ACADEMIC_TOKEN_35 est le produit scalaire standard entre la ACADEMIC_TOKEN_36-ième ligne de ACADEMIC_TOKEN_37 et la ACADEMIC_TOKEN_38-ième colonne de ACADEMIC_TOKEN_39 : ACADEMIC_TOKEN_2

3.3 Vue 3 : Somme de produits externes (Outer Products)

Le produit ACADEMIC_TOKEN_40 est la somme de ACADEMIC_TOKEN_41 matrices de rang 1 formées par les produits externes des colonnes de ACADEMIC_TOKEN_42 et des lignes de ACADEMIC_TOKEN_43 : ACADEMIC_TOKEN_3

3.4 Vue 4 : Multiplication par blocs

La méthode statique Matrix.block assemble une matrice à partir d'une grille de blocs sous-matriciels :

Python
A11 = Matrix([[1, 2], [3, 4]])
A12 = Matrix([[0], [0]])
A21 = Matrix([[5, 6]])
A22 = Matrix([[7]])

M_bloc = Matrix.block([
    [A11, A12],
    [A21, A22]
])
print(M_bloc)
# [1, 2, 0]
# [3, 4, 0]
# [5, 6, 7]

4. Analyse et Propriétés des Matrices

4.1 Tests structurels

Python
M = Matrix([[1, 0], [0, 1]])
print(M.is_square)        # True
print(M.is_symmetric)     # True
print(M.is_orthogonal)    # True (M.T @ M == I)
print(M.is_invertible())  # True

4.2 Inversion formelle (inv)

La méthode inv(strict=True) calcule l'inverse symbolique exacte via la réduction de Gauss-Jordan augmentée : - Si la matrice est numérique et singulière, elle lève une SingularMatrixError. - Si la matrice contient des paramètres, elle renvoie automatiquement un CaseSplit décrivant les conditions d'inversibilité et les inverses partielles.

Python
from linalg_pedagopy import Matrix, symbols

a, = symbols("a")
A = Matrix([[1, a], [0, 1]])
print(A.inv()) # Matrix([[1, -a], [0, 1]])

4.3 Réduction échelonnée, rang et sous-espaces fondamentaux

Les méthodes rref, rank et nullspace acceptent un paramètre assumptions pour spécifier des contraintes de branche :

Python
A = Matrix([
    [1, 2, 0, 1],
    [0, 1, 1, 0],
    [1, 3, 1, 1]
])

print(A.rank())        # 2
rref_mat, pivots = A.rref()
print(pivots)          # (0, 1)

# Base du noyau (Ker A)
ker = A.nullspace()
print(ker)             # Liste de vecteurs engendrant Ker(A)

# Base de l'image (Col A)
im = A.col_space()
print(im)              # Colonnes pivot de A
